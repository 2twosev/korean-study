# 한글 스터디 · 韩语全能学习助手

一个纯前端的韩语学习 Web 应用。听 · 说 · 读 · 写全覆盖，可调节发音音色，能导入 QQ 音乐歌曲做歌词精学，还能用「爱豆音色」陪你聊天并实时纠错韩语。

**无需安装、无需联网、无需注册** —— 打开就能用。

---

## 快速开始

### 方式一：双击直接打开（最简单）
双击 `index.html` 即可。适合只做听力、阅读、写作练习。

> ⚠️ 浏览器出于安全限制，`file://` 方式下**麦克风不可用**，所以「口语跟读打分」和「语音输入」会失效。要用麦克风请用方式二。

### 方式二：本地服务（推荐，功能完整）
```bash
node serve.js
```
然后浏览器打开 **http://127.0.0.1:8138/**

想换端口：`node serve.js 9000`

### 方式四：手机直接开公网链接（不限 WiFi）
双击 **`tunnel.bat`**：它会自动启动本地服务，再用 Cloudflare 免费隧道生成一个公网 HTTPS 地址，
窗口里打印出来，例如：
```
https://xxxx.trycloudflare.com
```
手机浏览器打开即可，**不用连同一个 WiFi，麦克风也能用**（因为是 HTTPS）。
缺点：电脑必须开着、窗口不能关，关掉链接就失效，属于临时方案。

### 方式五：永久地址（GitHub Pages，强烈推荐）
一次部署，地址**永久固定不变**，自带 HTTPS（手机麦克风可用），不依赖电脑开机。地址形如：

```
https://你的用户名.github.io/korean-study/
```

> 本项目已发布：**https://2twosev.github.io/korean-study/** （GitHub Pages，永久地址）

**三步搞定：**

1. **注册 GitHub**：打开 https://github.com/signup 用邮箱注册（免费）。

2. **生成 Token**：登录后进 https://github.com/settings/tokens
   → `Generate new token` → 选 **classic**
   → 勾选 **`repo`**（这一项就够）
   → 点 Generate → **复制那串 `ghp_` 开头的字符**（只显示一次）。

3. **双击 `deploy-github.bat`**：按提示输入用户名、Token、仓库名（直接回车用默认的 `korean-study`），
   脚本会自动建仓库、推送代码、开启 Pages，结束时打印你的永久地址。首次访问约 1–3 分钟生效。

> 注意：GitHub Pages 免费版要求仓库为 **public**，也就是页面任何人都能访问。
> 本项目是纯静态页面、无后端、学习数据只存在你自己的浏览器里，不含任何个人信息。

### 方式三：手机访问（同一 WiFi）
两步，全程双击即可，不用敲命令：

1. **右键 `firewall.bat` → 以管理员身份运行** —— 放行 8138 端口（只需做一次）。
2. **双击 `start.bat`** —— 启动服务，窗口里会打印手机要访问的地址，例如：
   ```
   手机访问:  http://192.168.0.110:8138/   （需连同一个 WiFi）
   ```
3. 手机连上**同一个 WiFi**，浏览器输入上面的地址。

> 防火墙那一步如果跳过，手机会一直转圈连不上。若 `firewall.bat` 提示权限不足，请确认是右键选的「以管理员身份运行」。

### 浏览器要求
- **必须使用 Edge 或 Chrome**（Firefox 不支持网页语音识别接口）。
- 若听不到韩语发音：Windows 请到「设置 → 时间和语言 → 语音」添加 **한국어(Korean)** 语音包。应用顶部「音色设置」页有环境自检，会告诉你缺什么。

### 手机端的两个限制（重要）
1. **麦克风跟读打分在手机上用不了** —— 浏览器规定麦克风只在 `https` 或 `localhost` 下开放，
   而手机通过 `http://192.168.x.x` 访问属于不安全上下文，会被禁用。
   除跟读打分外的功能（听力、阅读、写作、音乐、聊天打字、发音朗读）都正常。
   应用「音色设置 → 环境自检」会明确提示这一点。
2. **iOS Safari 的语音识别支持不完整** —— 跟读打分建议用 Android Chrome。iPhone 上朗读功能正常。

## 重点功能怎么用

### 1. 导入 QQ 音乐歌曲学习
应用**不联网抓取**（既稳定也不碰版权），歌词由你从 QQ 音乐复制后粘贴：

1. 打开 QQ 音乐，播放想学的韩语歌，进入歌词页。
2. 点歌词区「⋯ / 分享」→「复制歌词」，或长按歌词选中复制。
3. 粘贴进「音乐」页的输入框，点 **解析并导入**。

支持三种输入：
- **分享文案**（含《歌名》）：自动匹配内置曲库；没匹配到时提示你粘歌词。
- **LRC 带时间轴**：`[00:12.50]노래 가사` —— 时间轴会保留，可对照原曲进度。
- **纯歌词 / 双语歌词**：每行一句，韩语 + 中文翻译会被自动识别分开。

导入后得到：自动生成的罗马音、逐句朗读/慢速/跟读打分、歌词填空练习、生词收藏。

### 2. 调节音色
「音色设置」页：
- 顶部下拉选系统语音（韩语语音自动排在最前，标 🇰🇷）。
- 中间 6 组预设一键套用：甜美妹妹 / 清亮主唱 / 沉稳演员 / 温柔学长 / 低沉 Rapper / 播音员。
- 下方三根滑块精细调音高（0.5–2）、语速（0.4–1.6）、音量。
- 改完点「🔊 试听」立即听效果。

切换到不同爱豆时，会自动套用该角色推荐的音高语速。

### 3. 和爱豆聊天练韩语
- 左侧选角色（6 位，均为**虚构角色**，发音参数各不同）。
- 中间选难度：**轻松**（给罗马音+中文）/ **日常** / **挑战**（只给韩语，想看再点「👀 看翻译」）。
- 右侧纠错面板会记录你每一句的拼写、隔写、敬语、助词问题。
- 输入框下方**实时诊断**：打错字会立刻提示，还能点「用它替换」一键改正。
- 支持🎤语音输入（需要 http 方式打开 + 授权麦克风）。

### 4. 韩语纠错覆盖哪些
| 类型 | 例子 |
|---|---|
| 隔写 | 안되요 → **안 돼요**；하고 싶어요；할 수 있다 |
| 拼写 | 할께요 → **할게요**；오랫만 → **오랜만**；몇 일 → **며칠**；왠지 / 웬일 |
| 敬语 | 저는 학생이다 → **저는 학생이에요** |
| 助词 | 助词重复（는는 → 는） |
| 中文直译 | 提示改用韩语表达 |

## 数据管理

- 学习进度、生词本、纠错记录、音色偏好都存在**浏览器本地**（localStorage），换浏览器不互通。
- 「音色设置 → 数据管理」可导出 JSON 备份，或粘贴 JSON 导入恢复。
- 「清空全部数据」会重置一切（有二次确认）。

## 快捷键

- 听力 / 写作输入框：**Enter** = 检查答案
- 任意输入框：**Ctrl + Enter** = 朗读输入框内容

## 常见问题

**Q：完全没有声音？**  
A：① 确认用 Edge/Chrome；② 进「音色设置」看黄色提示条；③ 系统音量没静音；④ 点一下页面任意位置（部分浏览器要求用户交互后才允许播放语音）。

**Q：跟读打分点麦克风没反应？**  
A：① 必须是 http:// 打开（不能 file://）；② 浏览器地址栏要允许麦克风权限；③ Firefox 不支持，换 Edge/Chrome。

**Q：发音听起来像中文/英语？**  
A：说明系统里没有韩语语音包，应用降级用了其它语音。安装 Korean 语音包后刷新页面即可。

**Q：粘贴歌词后提示解析失败？**  
A：确认粘贴内容里有**韩文**（한글）。纯英文歌名或纯链接是解析不出歌词的。

## 目录结构

```
korean-study/
├── index.html          页面结构（8 个板块）
├── deploy-github.bat   【双击】一键发布到 GitHub Pages，得到永久地址
├── start.bat           【双击】启动服务（自动挑 Node 或 Python）
├── tunnel.bat          【双击】生成临时公网 HTTPS 链接（Cloudflare 隧道）
├── firewall.bat        【右键管理员运行】放行端口，手机才能连（只需一次）
├── serve.js            Node 版服务器（推荐）
├── serve.py            Python 版备用服务器（电脑没装 Node 时用）
├── css/style.css       样式（含移动端适配）
└── js/
    ├── data.js         韩语内容：字母表 / 10 课 / 词汇 / 纠错规则 / 爱豆 / 歌词
    ├── core.js         工具函数（编辑距离、差异比对）+ localStorage 存储
    ├── speech.js       语音合成 TTS 与语音识别 STT 封装
    ├── corrector.js    韩语纠错引擎
    ├── learn.js        听说读写四模块 + 虚拟韩文键盘
    ├── music.js        QQ 音乐导入、LRC 解析、韩文转罗马音
    ├── chat.js         爱豆对话 + 实时纠错面板
    └── app.js          路由、首页、设置页、全局初始化
```

采用普通 `<script>` 顺序加载 + `window.KC` 命名空间（**未使用 ES module**），所以双击 `index.html` 也能直接运行。
