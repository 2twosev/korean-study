韩文输入法小贴士

  • Windows：按 Win + 空格 或 Shift + 空格 切换到「韩国语」输入法。
  • 键盘对照：ㄱ=R, ㄴ=S, ㄷ=E, ㄹ=F, ㅁ=A, ㅂ=Q, ㅅ=T, ㅇ=D, ㅈ=W, ㅊ=C, ㅋ=Z, ㅌ=X, ㅍ=V, ㅎ=G
  • 紧音输入：Shift + ㄱㄷㅂㅅㅈ → ㄲ ㄸ ㅃ ㅆ ㅉ。
  • 也可以在下方直接打字，页面底部提供「虚拟韩文键盘」，无需安装输入法也能练习。

导入 QQ 音乐歌曲

粘贴 QQ 音乐的分享链接 / 分享文案 / 歌名，或者直接粘贴歌词（支持 LRC 时间轴），系统会生成逐句学习计划。

📋 不知道歌词怎么拿？点开看三步操作
  1. 打开 QQ 音乐，播放你想学的韩语歌，进入歌词页。
  2. 复制歌词：点击歌词区右上角「⋯ / 分享」→「复制歌词」；或长按歌词逐句选中复制。
  3. 粘贴到下方输入框，点「解析并导入」。带 [00:12.50] 时间轴的 LRC、纯歌词、带中文翻译的双语文本都能识别。
小提示：如果只粘贴分享文案（含《歌名》），会自动匹配内置曲库；匹配不到时再粘歌词即可。
本工具不联网抓取，歌词由你自己复制 —— 更稳，也不碰版权。
